# Online hardware replay

Two trials per objective; display Trial 01/02 corresponds to source recording 03/04.
JSON files contain plot samples and the corrected media-to-state time mapping; videos are unchanged source WebM files. No smoothing or resampling is applied. Each selected trial loads separately. Full logs and machine configuration are not included.

The video mapping pairs encoder timestamps with actual WebM packet timestamps. It preserves the correction of approximately 0.21–0.25 seconds relative to the original replay. Exposure timing is not calibrated.
